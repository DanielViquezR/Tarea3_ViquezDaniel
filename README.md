## Descripción

Proyecto individual desarrollado en R, Quarto y Excel para analizar transacciones mediante ventanas móviles, la ley de Benford y el cálculo de valores acumulados con interés.

## Estructura del proyecto

- `base/`: archivos originales proporcionados por el docente.
- `cod/`: scripts y funciones de R.
- `data/`: bases de datos generadas.
- `config/`: parámetros de los ejercicios.
- `excel/`: cálculos y verificaciones en Excel.
- `info/`: gráficos y figuras.

## Reproducción

1. Clonar este repositorio.
2. Clonar la base del docente en `base/`.
3. Ejecutar `cod/01_datos.R` con el carné correspondiente.
4. Ejecutar el documento `Tarea3_ViquezDaniel.qmd` para generar el reporte HTML.
5. Consultar el archivo de Excel para verificar los resultados.
